# Safety logistic classifier artifact v1

The standalone semantic safety classifier is stored under `data/runtime/safety_classifier/` by
default. Generated artifacts are runtime data and are not committed.

## Files

- `model.npz`: NumPy arrays loaded with `allow_pickle=False`.
- `manifest.json`: training provenance, filters, threshold, evaluation metrics, and SHA-256 of the
  model file.

Required model arrays:

```text
weights    float32[1024]
intercept  float64 scalar
threshold  float64 scalar in [0, 1]
dimensions int32 scalar, currently 1024
```

## Runtime guarantees

- The query embedding is generated by `BAAI/bge-m3` through Hugging Face `hf-inference` and
  L2-normalized before prediction.
- `unsafe` is the positive class.
- `unsafe_probability >= threshold` maps to `unsafe`; lower values map to `safe`.
- Loading fails on schema mismatch, checksum mismatch, invalid dimensions, or non-finite weights.
- Runtime prediction requires NumPy but not scikit-learn or pickle.

## Training filters

Only rows satisfying all of the following are eligible:

```text
task_type == "safety"
input_label in {"safe", "unsafe"}
has_image == false
```

This artifact is an experimental classifier contract. It must not become the production safety
gate until evaluated against the official Nemotron validation and test splits.
